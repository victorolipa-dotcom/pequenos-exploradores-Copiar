# Pequeños Exploradores

Site estático em HTML, CSS e JavaScript, com imagens e fontes locais.

## Enviar ao GitHub

1. Extraia este ZIP no computador.
2. Crie um repositório no GitHub.
3. Envie o conteúdo desta pasta para a raiz do repositório: `index.html`, `vercel.json`, `assets/` e este README.
4. Não envie o ZIP como arquivo único. O `index.html` deve aparecer diretamente na raiz do repositório.

## Importar na Vercel

Importe o repositório como projeto. Se houver detecção de framework, selecione **Other**.

- Root Directory: raiz do repositório.
- Build Command: deixe vazio (Override ativado, se necessário).
- Output Directory: `.` (raiz).
- Install Command: deixe vazio.

Não são necessárias dependências, variáveis de ambiente nem etapa de compilação.

## Conteúdo

- `index.html`: página completa com estilos, scripts e configuração incorporados.
- `assets/`: artes, amostras e fontes; preserve a estrutura da pasta.
- `vercel.json`: configuração simples de hospedagem estática.

Os dois kits direcionam aos links Hotmart aprovados, com checkoutMode=10.

Este pacote preserva o conteúdo aprovado da prévia, incluindo avisos de prévia e informações do vendedor ainda pendentes. Nenhuma publicação foi realizada na preparação do pacote.
